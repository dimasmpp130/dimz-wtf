## ✦ About

**DIMZ WTF** adalah project web yang dibuat sebagai tempat berkumpulnya berbagai tools digital dalam satu website.

Tujuannya sederhana:

> **Buka satu website, cari tools yang dibutuhkan, langsung gunakan.**

Project ini terus dikembangkan dengan tampilan yang sederhana, responsif, cepat, dan nyaman digunakan baik melalui **HP maupun desktop**.

---

## 🚀 Features

| Category        | Description                                      |
| --------------- | ------------------------------------------------ |
| 📥 Downloader   | Berbagai tools untuk membantu kebutuhan download |
| 🎨 Generator    | Tools untuk membuat konten secara cepat          |
| 🛠️ Utilities   | Berbagai tools kecil yang berguna sehari-hari    |
| 🎮 Gaming Tools | Tools dan utilities bertema gaming               |
| 📱 Responsive   | Nyaman digunakan dari smartphone maupun desktop  |
